# Hoo's Fishing

## Overview

Hoo's Fishing is a casual fishing game where the player controls an owl and works to catch better fish over time. The player can catch fish, sell them for money, and use that money to improve their equipment. As the player gets better gear, they can continue progressing and catch more valuable fish.
